# Tasks

A weekly task board (Mon–Sun + Deadlines). The page is hosted on GitHub Pages;
the data is one JSON file (`tasks.json`) in a secret GitHub Gist.

- Done tasks stay struck through for the rest of the week; done tasks from
  previous weeks are deleted the next time the page is opened.
- Unfinished tasks carry over to the same weekday.
- Ticking a deadline removes it.
- Tap a task to edit it, move it to another day, or delete it. On a laptop
  you can also drag tasks between days.

## How access works

Saving to a gist needs a GitHub token. `setup.html` encrypts the token (and the
gist id) with your passphrase, in your browser, and gives you `config.js`.
Only that encrypted blob is public. On each device you type the passphrase once;
the browser then remembers the unlocked token until you press **Lock**.

## Files

- `index.html` – the app
- `setup.html` – one-off page that creates the gist and `config.js`
- `crypto.js` – passphrase encryption (PBKDF2 + AES-GCM), used by both pages
- `config.js` – your encrypted token + gist id (generated by setup)
